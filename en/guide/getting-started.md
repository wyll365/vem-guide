# Getting Started

This guide is for **merchant operators** using the VEM vending machine admin console. Channel staff should see the [Channel Guide](/en/channel/index) instead.

## Sign In

Open the admin console URL and sign in with your account and password. After signing in, the left-hand menu contains all vending machine features:

![Dashboard](/images/dashboard.png)

| Menu | What it's for |
|---|---|
| Home | Dashboard: revenue, orders, device status, and low-stock alerts at a glance |
| Devices | Device list/groups/map, alarm center, restocking records, staff authorization |
| Products | Manage products and categories |
| Orders | Look up orders, trace the dispensing flow, issue refunds |
| Templates | Design the machine's on-screen layout |
| Reports | Sales summary and product sales rankings |
| Marketing | Promotions and promo codes |
| Settings | Service hotline, alert email notifications |

## Three Steps to Go Live: Get Your First Machine Selling

1. **[Onboard the device](/en/guide/device)** — Copy the merchant registration code from the Home page, enter it on the device to complete binding, then open the device detail page to fill in the name, group, and low-stock alert threshold.
2. **[Create products](/en/guide/product)** — Create product categories first, then publish products (title, price, cover image, attributes).
3. **[Assign products to slots](/en/guide/stock)** — Open the device's slot page, assign products to slots, and set the stock. Once done, the machine is ready to sell.

To make the screen look better, you can also do [screen design](/en/guide/template) (fastest way: import the default template and bind it to the device).

## Daily Checklist

- Every morning, glance at the [Home dashboard](/en/guide/report): yesterday's revenue, low-stock alerts, and whether all devices are online;
- Handle any [alerts](/en/guide/alarm) promptly, and [restock](/en/guide/restock) when stock runs low;
- If a customer reports a failed dispense, check the dispensing flow in [Orders](/en/guide/order) and issue a refund if needed.
