# 快速上手

本手册面向使用 VEM 售卖机管理后台的**商户运营人员**;渠道人员请看 [渠道操作指南](/channel/index)。

## 登录

打开管理后台地址,输入账号密码登录。登录后左侧菜单即为售卖机相关功能:

![经营看板](/images/dashboard.png)

| 菜单 | 用来做什么 |
|---|---|
| 首页 | 经营看板:收入、订单、设备状态、库存预警一屏总览 |
| 设备管理 | 设备列表/分组/地图、告警中心、补货记录、管理人员授权 |
| 商品管理 | 商品与分类维护 |
| 订单管理 | 查订单、看出货流程、退款 |
| 设备模板 | 机器屏幕界面的装修 |
| 经营报表 | 销售汇总与商品销量排行 |
| 营销活动 | 促销活动与优惠码 |
| 设置管理 | 服务热线、告警邮件通知 |

## 上线三步:让第一台机器卖起来

1. **[接入设备](/guide/device)** — 在首页复制商户注册码,设备端输入注册码完成绑定;再到设备详情完善名称、分组、库存预警阈值。
2. **[建立商品](/guide/product)** — 先建商品分类,再发布商品(标题、价格、封面、属性)。
3. **[排货与上架](/guide/stock)** — 进设备的货道页,把商品排到货道并上库存。完成后机器即可售卖。

想让屏幕更好看,可以再做 [屏幕装修](/guide/template)(最快方式:导入默认模板后绑定到设备)。

## 每天要做的事

- 早上看一眼 [首页看板](/guide/report):昨日收入、库存预警、设备是否都在线;
- 有 [告警](/guide/alarm) 及时处理,缺货就去 [补货](/guide/restock);
- 顾客反馈没出货,到 [订单管理](/guide/order) 查出货流程,必要时退款。
