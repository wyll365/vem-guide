# 系统设置

菜单:**设置管理**。页面分两张卡片,各自独立保存。

![设置管理](/images/settings.png)

## 全局设置

| 项 | 说明 |
|---|---|
| 服务热线 | 所有设备屏幕默认展示的客服电话。个别设备想用不同号码,可在该设备详情的"专属服务热线"单独设置 |

## 告警邮件通知

设备产生新告警时,向指定邮箱发送邮件提醒。

| 项 | 说明 |
|---|---|
| 启用邮件通知 | 总开关 |
| 接收邮箱 | 输入邮箱后回车添加,可填多个 |
| 关注告警类型 | 只对勾选的类型发邮件,**留空 = 全部类型** |
| 关注告警级别 | 提示/警告/严重,**留空 = 全部级别**(与类型同时满足才发) |
| 邮件模板ID | 需与邮件配置(SMTP)中创建的告警模板同名,否则发不出 |
| 邮件语言 | 中文 / English |

::: warning 前置条件
发信依赖商户已配置好的**邮件(SMTP)发信账号与告警模板**,该配置不在本应用内,请先完成 SMTP 配置再启用。
:::
