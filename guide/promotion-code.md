# 优惠码

菜单:**营销活动 › 优惠码**

优惠码是顾客在售卖机付款界面**输入 8 位码**才能享受的优惠,适合线下投放、私域发放等场景。

## 第一步:创建优惠码活动

![优惠码活动](/images/promotion-code-list.png)

点右上角 <Badge type="tip" text="+" />,大部分字段与促销活动相同,额外注意:

| 字段 | 说明 |
|---|---|
| 活动类型 | 满减 / 折扣 / **免费兑换**(指定商品免单) |
| 兑换商品 | 仅"免费兑换"需要:勾选可兑换的商品,顾客购物车须**恰好 1 种商品 1 件**且在清单内 |
| 单设备可用次数 | 该活动在同一台机器上最多核销几次,0 = 不限 |
| 活动总次数 | 该活动全局最多核销几次,0 = 不限 |

::: warning 活动改动影响所有在外流通的码
已生成的码始终跟随活动当前规则——修改门槛/优惠值等于改了所有已发出的码;关闭"启用"开关则所有码立即失效(适合紧急熔断)。
:::

## 第二步:生成码

在活动行点 **优惠码管理** 进入码列表,点 **生成**:

| 生成方式 | 说明 |
|---|---|
| **批量随机** | 填数量(1~10000),系统随机生成,**每个码固定只能用 1 次**。同批次共用一个批次号,可整批作废 |
| **自定义码面** | 手输 8 位码(数字+大写字母),可设**单码可用次数**(0=不限),适合做"通用码"投放 |

::: tip 自定义码面避开易混字符
系统会把 I、L 识别为 1,O 识别为 0,且不支持 U。建议只用数字和 `A-H J K M N P Q R S T V W X Y Z`。
:::

码列表中可按码面/批次/状态搜索,勾选后可批量作废:

![优惠码列表](/images/promotion-codes.png)

## 第三步:发码与核销

- **发码**:点 **导出 CSV** 下载全部码面,自行用于印刷、投放、私信发放(系统不提供短信/微信推送)。
- **核销**:顾客在售卖机付款界面输入码,机器自动校验并抵扣;后台无需人工核销。
- **查结果**:码列表的"可用次数"列显示 `已用/上限`;点行内 **核销流水** 查看每次使用的订单、金额和状态。

核销流水的三种状态:

| 状态 | 含义 |
|---|---|
| 锁定中 | 顾客已下单未付款,次数被预占 |
| 已核销 | 付款成功,正式使用 |
| 已释放 | 订单取消或全额退款,次数已退回,码可再用 |

## 管理码

- **作废** / **作废整批**:作废后不可恢复,顾客再输提示无效。
- 码面搜索很宽容:带不带连字符、大小写、抄错 I/L/O 都能搜到。
- 码生成后**不能修改**,只能作废重发。

## 规则要点

- 一笔订单最多用 **1 个**优惠码;可与自动促销叠加(先促销后码,门槛按折后价判定)。
- 同一台机器连续输错 5 次会锁 10 分钟,防止暴力试码。
- 优惠码不会在机器屏幕上主动展示,需要运营自行告知顾客。
