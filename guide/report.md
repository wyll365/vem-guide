# 工作台与报表

## 首页(经营看板)

登录后默认进入 **首页**,一屏掌握今天的生意:

![经营看板](/images/dashboard.png)

- **四张指标卡**:今日收入、今日订单、本月收入、在线设备(在线/总数)。
- **近 15 天趋势**:收入/订单两个页签切换。
- **设备状态**:在线率环形图;下方是**商户注册码**(新设备绑定用,可复制;刷新会使旧码失效)。
- **热销商品**:今日/本周/本月销量排行(数据约每小时更新一次)。
- **最近订单**:最新成交明细,点"全部订单"进订单管理。
- **库存预警**:哪些设备哪些商品低于预警阈值,点行尾 **补货** 直达该设备货道页。

::: tip 库存预警的前提
设备必须先在 **设备详情 › 编辑资料** 中设置"库存预警阈值"(≥1),没设阈值的设备不会出现预警。
:::

## 经营报表

菜单:**经营报表**

![经营报表](/images/report.png)

- **时间档**:今日 / 本周(周一起) / 本月(1 日起),均为截至当前的累计值。
- **三张汇总卡**:成交订单笔数、**营收金额(已收款实收 − 已退款,即净收入)**、退款金额。
- **商品销量排行**:按销量降序,最多展示前 100 名;点 **导出 CSV** 可下载排行数据。

::: info 口径说明
- 收入均为**扣除退款后的净额**;订单数**包含**已退款订单,所以"订单数 × 客单价"不等于收入。
- 统计按**下单时间**归属(UTC+8)。
- 首页"热销商品"有约 1 小时缓存,与报表页实时数据可能短暂不一致,以报表页为准。
:::
