# 促销活动

菜单:**营销活动 › 促销活动**

促销活动是**自动生效**的优惠:顾客在机器上下单时满足条件即自动打折,无需输入任何东西。

![促销活动](/images/promotion-list.png)

## 创建活动

点右上角 <Badge type="tip" text="+" />,填写:

| 字段 | 说明 |
|---|---|
| 活动名称 | 自定义 |
| 活动类型 | **满减** 或 **折扣** |
| 门槛金额(元) | 订单原价合计需达到此金额才生效,**填 0 表示无门槛**(满减+门槛 0 = 立减) |
| 减免金额 / 折扣 | 满减:直接减多少元;折扣:填**付款百分比**,如填 90 = 9 折(顾客付 90%) |
| 适用范围 | 全部设备,或指定设备(弹窗勾选) |
| 生效时间 | 起止时间,**不选 = 长期有效** |
| 排序 | 数字越大列表越靠前 |
| 启用 | 开关,关闭立即失效 |

::: danger 折扣填法最易错
"折扣"填的是**顾客付款的百分比**,不是折掉多少:想打 9 折填 **90**,打 5 折填 **50**。填 10 会变成 1 折!
:::

## 规则要点

- 促销按**订单总价**计算,只能限定设备范围,不能按商品限定。
- 一笔订单命中多个促销活动时,**只生效优惠力度最大的一个**,不叠加。
- 促销可以与 [优惠码](/guide/promotion-code) 叠加:先算促销,优惠码在折后价基础上再算。
- 想临时停用,进编辑弹窗把"启用"关掉即可,立即生效。
