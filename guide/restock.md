# 补货

## 日常补货怎么做

补货操作在**设备的货道页**完成:**设备管理 › 设备列表 › 目标设备 › 补货**,详细步骤见 [③ 排货与上架](/guide/stock)。

线下补货员也可以用移动端补货——前提是商户在 [管理人员](/guide/device#管理人员设备授权) 中给该员工授权了"补货"权限和设备范围。

## 补货记录

菜单:**设备管理 › 补货记录**

![补货记录](/images/restock-list.png)

所有补货流水按补货时间倒序展示,后台补货和移动端补货员的操作记录在同一张表里:

| 列 | 说明 |
|---|---|
| 补货时间 | 操作发生时间 |
| 设备 / 货道 | 哪台设备的哪个货道(显示货道编码/硬件编号) |
| 商品 | 该货道当时排的商品 |
| 补货前 / 补货后 / 补货数量 | 本次库存变化 |
| 操作人 | 谁补的货 |

::: tip
只有**增加库存**的操作会产生补货记录;退库存(填负数)不计入本表。
:::
