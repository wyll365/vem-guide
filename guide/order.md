# 订单与退款

菜单:**订单管理**

![订单列表](/images/order-list.png)

## 查订单

支持按订单号(需完整)、商品名称、设备名称、设备号、订单状态、下单时间区间筛选。

::: tip 先选时间范围再查
订单量大时,带上时间范围查询会快很多,建议养成习惯。
:::

列表关键列:

- **子订单**:一笔订单包含的商品明细(图片/单价/数量/小计)。
- **总金额 / 优惠金额 / 实收金额**:总金额 − 优惠 = 实收;已有退款时实收下方红字显示"已退:xx"。
- **出货流程**:点开右侧抽屉,按时间轴查看这笔订单从支付到出货的每一步日志,**排查"顾客说没出货"就看这里**。

## 订单状态

| 状态 | 含义 |
|---|---|
| 未支付 | 已下单未付款 |
| 已支付 | 付款成功,尚未开始出货 |
| 出货中 | 已向机器下发出货指令 |
| 已出货 | 出货完成 |
| 出货异常 | 出货过程异常(如卡货),**需关注并视情况退款** |
| 已退款 | 已全额退款 |
| 已取消 | 订单取消 |

## 退款

在订单行点红色 **退款** 按钮(仅**扫码支付**且状态为已支付/出货中/已出货/出货异常、尚有可退余额的订单才会出现)。

弹窗中:

- **可退金额** = 实收金额 − 累计已退;
- **退款金额** 默认全额,可改小做**部分退款**,同一订单可多次部分退;
- 填写退款原因(选填,如"掉货失败"),点 **退款**。

::: danger 退款不可撤销
退款经原支付渠道退回给买家,提交后无法撤回。
:::

规则说明:

- 现金、刷卡、免费订单不支持在线退款。
- 退满全额后订单状态才变"已退款",此时订单占用的优惠码会自动释放;部分退款不改变状态、不释放优惠码。
- 每次退款都会记入该订单的"出货流程"日志(含金额、原因、操作人)。
