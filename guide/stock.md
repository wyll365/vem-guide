# ③ 排货与上架

商品建好后,要把它"排"到设备的货道上,机器才会售卖。排货和补货在同一个页面完成。

## 进入货道页

菜单:**设备管理 › 设备列表**,找到目标设备卡片,点 **补货** 按钮。

![货道矩阵](/images/device-stock.png)

页面顶部是设备信息(名称/编码/类型,只读),下方按"行"展示货道矩阵,每格对应机器里的一个货道,显示货道编码、已排商品和当前库存。

::: info 货道结构从哪来?
货道的行列数、编码、**最大库存**由渠道方在"设备类型"中预先定义,商户端只能排商品和加减库存,不能增删货道。如果货道结构和实机不符,请联系渠道方调整设备类型。
:::

## 给货道排商品

- **单个货道**:空货道点 **选择**,已有商品的货道点 **切换商品**,在弹出的商品选择器中按分类/名称筛选后点选商品,选定即生效,无需再点保存。
- **整行统一排**:点行卡片右上角 **选择第 N 行商品**,选中的商品会套用到该行**所有**货道(适合整排卖同一款)。

## 给货道上库存

- **单个货道**:点货道格里的 **更新** 按钮,弹窗显示 `当前:x / 最大:y`,填入本次**增加的数量**(也可填负数退库存),或点 **填充最大** 一键补满,再点 **确定更新**。
- **整行补满**:点行卡片右上角 **上第 N 行库存**,确认后该行每个货道都补到各自的最大库存。

::: warning 注意
- 单次补货数量不能超过"最大库存 − 当前库存",退库存不能超过当前库存。
- 整行操作是逐个货道依次执行的,如中途报错,建议刷新页面核对实际结果。
:::

每次补货成功都会记入 [补货记录](/guide/restock);系统同时会通知设备刷新商品和库存展示。
